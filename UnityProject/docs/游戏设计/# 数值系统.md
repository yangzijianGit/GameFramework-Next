## 1. 货币系统

### 1.1 货币类型

| 货币ID | 名称 | 获取途径 | 用途 |
|--------|------|----------|------|
| Diamond | 钻石 | 充值/成就 | 购买道具/复活 |
| dust | 灰尘 | 关卡掉落 | 升级建筑 |
| energy | 体力 | 时间恢复/购买 | 挑战关卡 |
| move | 步数 | 道具补充 | 关卡内行动 |
| star | 幸福星 | 关卡奖励 | 建筑升级 |

### 1.3 货币获取接口

```csharp
public long GetCurrencyCount(string type)
{
    switch (type)
    {
        case CurrencyType.Diamond: return m_Diamond;
        case CurrencyType.dust: return m_nDust;
        case CurrencyType.energy: return m_mEnergy;
        case CurrencyType.move: return m_move;
        case CurrencyType.star: return m_nHappinessStar;
        default: return 0;
    }
}
```

## 3. 服装系统

### 3.1 服装数据结构

```csharp
public class ClothesInfo
{
    public int m_nLevel;  // 等级
    public int m_nExp;    // 经验
}

private Dictionary<string, ClothesInfo> m_mpClothes = new Dictionary<string, ClothesInfo>();
private string m_strCurrentClothId;
private string m_strClothSkillType;
```

### 3.2 服装操作

```csharp
// 获取服装
public void addCloth(string clothId, int level, int exp)
{
    m_mpClothes[clothId] = new ClothesInfo() { m_nExp = exp, m_nLevel = level };
}

// 更新服装
public void refreshCloth(string clothId, int level, int exp)
{
    if (m_mpClothes.ContainsKey(clothId))
    {
        m_mpClothes[clothId].m_nLevel = level;
        m_mpClothes[clothId].m_nExp = exp;
    }
    else
    {
        addCloth(clothId, level, exp);
    }
}

// 检查服装是否存在
public bool isClothExist(string clothId)
{
    return getClothLevel(clothId) != -1;
}

public int getClothLevel(string clothId)
{
    if (m_mpClothes.ContainsKey(clothId))
        return m_mpClothes[clothId].m_nLevel;
    return -1;
}
```

### 3.3 当前服装

## 5. 数值计算公式

### 5.1 分数计算

| 因素 | 计算方式 |
|------|----------|
| 基础消除 | 消除数 × 10 |
| 连锁加成 | 基础分 × (1 + 连锁次数 × 0.5) |
| 技能加成 | 技能额外分 |
| 狂热加成 | 最终分 × 狂热倍率 |

### 5.2 货币产出

| 来源 | 基础产出 | 倍率因素 |
|------|----------|----------|
| 关卡奖励 | 100-500 | 星级/难度 |
| 每日任务 | 50-200 | 任务类型 |
| 成就奖励 | 500-5000 | 成就等级 |
