# 🎮 游戏机制详解

## 1. 消除系统

### 1.1 基础规则

#### 匹配条件
- **横向匹配**: 同一行连续3个及以上相同元素
- **纵向匹配**: 同一列连续3个及以上相同元素
- **L型/T型匹配**: 横向+纵向交叉，消除区域更大

#### 交换规则
- 只能交换相邻且水平/垂直方向的两个元素
- 交换后必须产生至少一个有效匹配
- 无效交换会还原原位

### 1.2 消除流程

```
Step 1: 元素交换
Step 2: 检测匹配 (横向/纵向)
Step 3: 执行消除 (播放特效、移除元素)
Step 4: 元素下落 (上方元素掉落)
Step 5: 填充新元素 (顶部生成)
Step 6: 再次检测 (连锁消除)
```

### 1.3 元素类型

| 元素ID | 名称 | 描述 |
|--------|------|------|
| 1 | 红色元素 | 基础消除元素 |
| 2 | 蓝色元素 | 基础消除元素 |
| 3 | 绿色元素 | 基础消除元素 |
| 4 | 黄色元素 | 基础消除元素 |
| 5 | 紫色元素 | 基础消除元素 |
| 6 | 特殊元素 | 需特殊条件触发 |

### 1.4 匹配算法

```csharp
// 伪代码：匹配检测
function CheckMatch(grid):
    matches = []

    // 横向检测
    for row in 0..GRID_HEIGHT:
        for col in 0..GRID_WIDTH - 2:
            if grid[row][col] == grid[row][col+1] == grid[row][col+2]:
                matches.add(GetMatchRegion(row, col, HORIZONTAL))

    // 纵向检测
    for col in 0..GRID_WIDTH:
        for row in 0..GRID_HEIGHT - 2:
            if grid[row][col] == grid[row+1][col] == grid[row+2][col]:
                matches.add(GetMatchRegion(row, col, VERTICAL))

    return matches
```

## 2. 技能系统

### 2.1 技能类型

| 技能类型 | 触发时机 | 示例 |
|----------|----------|------|
| 消除技能 | 元素被消除时 | 消除后额外消除周围 |
| 生成技能 | 特定条件满足时 | 随机生成特殊元素 |
| 回合结束技能 | 每回合结束时 | 消除所有某种元素 |
| 特殊技能 | 玩家主动触发 | 消除指定区域 |

### 2.2 技能配置结构

```json
{
  "skill": {
    "id": "skill_001",
    "name": "火焰爆炸",
    "type": "eliminate",
    "condition": {
      "minMatch": 4,
      "elementType": "fire"
    },
    "effect": {
      "range": 3,
      "damage": 100
    },
    "priority": 1
  }
}
```

### 2.3 技能优先级

- **规则**: 多个技能触发时，按优先级顺序执行
- **配置**: `Events_Config` 中的 `roundEndPriority` 字段
- **实现**: `SkillConfig.cs` 中 `getFirstRoundEndPriority()` 获取最高优先级

### 2.4 技能效果实现

#### 消除技能
```csharp
public static List<SkillNode> getDestroySkillNode(string element)
{
    foreach (var event in JsonManager.events_config.root.game.events)
    {
        if (event.id == JsonManager.events_config.root.game.eliminate)
        {
            foreach (var index in event.eventSkill.index)
            {
                if (index.strElementId == element)
                    return index.skillNode;
            }
        }
    }
    return null;
}
```

## 3. 狂热模式

### 3.1 触发条件

- 连续消除达到一定次数
- 单次消除达到一定数量
- 收集狂热能量达到阈值

### 3.2 狂热效果

| 效果 | 描述 |
|------|------|
| 时间延长 | 增加步数/时间限制 |
| 能量加成 | 技能效果翻倍 |
| 特殊元素 | 自动生成特殊元素 |
| 分数加成 | 获得额外分数 |

### 3.3 实现逻辑

```csharp
// PlayerData.cs 中的狂热系统
public long lFeverPowerNum { get; set; }
public long lCheckFeverCount { get; set; }

        (float)Data.PlayerData.Instance.lFeverPowerNum / lCheckFeverCount

}
```

## 4. 回合机制

### 4.1 回合流程

```
回合开始
    ↓
玩家操作 (交换元素)
    ↓
匹配检测
    ↓
消除处理 + 技能触发
    ↓
元素下落 + 填充
    ↓
连锁检测 (有则返回匹配检测)
    ↓
回合结束技能
    ↓
回合结束
```

### 4.2 回合状态管理

| 状态 | 说明 |
|------|------|
| 玩家操作中 | 等待玩家交换元素 |
| 消除中 | 执行消除动画和逻辑 |
| 掉落中 | 元素下落动画 |
| 结算中 | 回合结束计算 |

## 5. 特殊机制

### 5.1 元素交换限制

- 不能交换正在消除的元素
- 不能交换正在下落的元素
- 动画播放期间禁止操作

### 5.2 死局检测

- 检测棋盘是否存在有效移动
- 无有效移动时，自动重新洗牌
- 洗牌次数有限制

### 5.3 特殊消除

- **四连消除**: 生成爆炸元素
- **五连消除**: 生成核武器
- **L/T型消除**: 生成闪电元素
