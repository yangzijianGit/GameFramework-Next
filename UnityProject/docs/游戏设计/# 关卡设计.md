# 📋 关卡设计文档

## 1. 关卡系统概述

### 1.1 关卡分类

| 类型 | ID | 描述 |
|------|-----|------|
| 普通关卡 | 0 | 常规三消，目标收集 |
| 精英关卡 | 1 | 高难度，奖励丰富 |
| Boss关卡 | 2 | Boss机制，特殊技能 |

## 2. 关卡配置字段说明

### 2.1 基础字段

| 字段 | 类型 | 说明 |
|------|------|------|
| missionId | string | 关卡唯一ID |
| missionName | string | 关卡名称 |
| missionType | string | 关卡类型 (0普通/1精英/2Boss) |
| maxMove | int | 最大步数限制 |

### 2.2 胜利条件

| 条件类型 | 说明 |
|----------|------|
| score | 达到指定分数 |
| collect | 收集指定数量元素 |
| eliminate | 消除指定元素 |
| time | 在限定时间内完成 |

### 2.3 星级条件

- **1星**: 最低达成目标
- **2星**: 中等达成目标
- **3星**: 完美达成目标

```csharp
// 星级判定示例
public int GetStarLevel(Mission mission, PlayerResult result)
{
    int star = 0;
    foreach (var condition in mission.starCondition)
    {
        if (CheckCondition(condition, result))
            star++;
    }
    return star;
}
```

## 3. 关卡进度管理

### 3.1 关卡解锁机制

| 条件 | 说明 |
|------|------|
| 通关前置关卡 | 完成上一关即可解锁 |
| 达到玩家等级 | 玩家达到指定等级 |
| 消耗道具 | 使用道具解锁 |

### 3.2 关卡数据存储

```csharp
// PlayerData.cs 中管理
public string CurrentMissionId { get; set; }
public JsonData.Stage_mission_Client.Mission CurrentMissionData { get; }

public string GetNextMissionId(string currentMissionId)
{
    for (int i = 0; i < JsonManager.mission_client.root.game.mission.Count; i++)
    {
        if (JsonManager.mission_client.root.game.mission[i].missionId == currentMissionId)
        {
            return JsonManager.mission_client.root.game.mission[i + 1].missionId;
        }
    }
    return "";
}
```

// MissionConfig.cs
public static JsonData.Stage_mission_Client.Mission getMissionConfig(string missionId)
{
    foreach (var mission in JsonManager.mission_client.root.game.mission)
    {
        if (mission.missionId == missionId)
            return mission;
    }
    return null;
}

public static bool isBossMission(string missionType)
{
    return int.Parse(missionType) == 1;
}

## 6. 关卡设计原则

### 6.1 难度曲线

| 阶段 | 关卡范围 | 难度特征 |
|------|----------|----------|
| 新手期 | 1-10 | 简单规则，熟悉操作 |
| 成长期 | 11-30 | 引入新机制 |
| 挑战期 | 31-50 | 高难度技巧关 |
| 精通期 | 50+ | 极限操作关 |

### 6.2 节奏设计

- 前3关: 无压力，通过教学
- 4-6关: 引入第一个机制
- 每5关: 引入新元素
- 每10关: 阶段性Boss

### 6.3 奖励设计

| 首次通关 | 星级奖励 | 额外奖励 |
|----------|----------|----------|
| 基础货币 | 道具奖励 | 成就点数 |
| 解锁新功能 | 服装碎片 | 排行榜积分 |
